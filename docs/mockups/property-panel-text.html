Property panel — annotation text MOCK v2

Panel for a selected TextItem (Block Editor / model space), rows from TextItem.get_properties(). Locked layout:

  • Text — Content
  • Format — Font · Height (bare pixels, no unit) · B/I/U buttons · Alignment · Font colour
  • Frame — Border · Corner (icon seg) · Line type · Line weight
  • Fill — Fill colour · Opacity 0–100% (new: evolves opaque_bg → fill colour+alpha)

Toggle Border/Fill on to see dependent rows enable. Click a swatch to cycle colour / none.
